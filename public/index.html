Program Pendidikan ACDI

Pilih jalur pelatihan sesuai minat dan rencana kariermu.

PROGRAM 01

Pramugari Pesawat

Persiapan pengetahuan, penampilan, dan keterampilan untuk proses rekrutmen bidang awak kabin.

PROGRAM 02

Pramugari KAI

Persiapan kompetensi dan pelayanan untuk peluang karier di bidang layanan kereta api.

PROGRAM 03

Staff Bandara

Pembekalan keterampilan pelayanan dan persiapan mengikuti proses rekrutmen di lingkungan bandara.

PROGRAM 04

Ausbildung Jerman

Program persiapan untuk peluang pendidikan dan pelatihan vokasi di Jerman. Informasi persyaratan dan jalur program dapat dikonfirmasi kepada staf ACDI.

PROGRAM BEASISWA HINGGA 50% Tersedia kesempatan beasiswa hingga 50%. Hubungi staf ACDI untuk informasi ketentuan dan proses seleksi.
